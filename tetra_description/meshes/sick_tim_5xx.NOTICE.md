# sick_tim_5xx.stl

SICK TiM5xx 외형 메쉬. M 앞 라이다(TiM571, frame `laser`)를 RViz·웹 3D 화면에 그리려고 가져왔다.

- 출처: sick_scan_xd (`tetra_dependency/sick_scan_xd-develop/meshes/sick_tim_5xx.stl`), SICK AG
- 라이선스: Apache License 2.0 (원본 저장소의 LICENSE)
- 단위 m, 원점 = 레이저 광학 중심 (sick_scan.urdf.xacro 의 z_offset 설명). 그래서 `laser` 링크에 오프셋 없이 붙인다.
